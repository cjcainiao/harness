# 图片生成

1. 确认用户要获得一张新图片；仅要求分析已有图片时不要生图。
2. 从用户描述整理主体、场景、风格、光线、构图与画幅。缺少非关键细节时做合理补全，不因小细节反复追问。
3. 若用户要求参考本轮上传的图片生成或编辑，从附件清单取得该图片的文件标识。仅凭附件清单无法了解图像细节，未经查看不要编造图片内容；用户给出的修改描述可直接作为画面要求。
4. 用 `tool_search` 查找 `generate_image`，传入明确的画面描述、合适的画幅；参考图生图时还要传入对应的文件标识。若附件清单有多张图片且用户未指明参考哪张，先询问。
5. 等待工具返回真实结果。成功时说明图片已生成，可在当前聊天消息中预览和下载；失败时说明工具返回的原因，不声称已有图片。

聊天模型不支持视觉时仍可使用上传图片作生图参考，但不能声称自己已看懂图片内容。
